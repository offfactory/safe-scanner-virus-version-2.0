About the project

Local-first protection, clearly explained.

What it does

SafeScan scans local files with SHA-256 signatures and conservative heuristics. It reports reasons instead of making exaggerated security claims.

Real-time protection

Windows includes an experimental local FileSystemWatcher module for selected folders. It is not a guaranteed replacement for a full security suite.

Assistant status

The security assistant is coming soon. Current releases keep scanning offline and do not send files, passwords, cookies, or tokens to a cloud service.

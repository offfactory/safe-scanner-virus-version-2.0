# SafeScan Defender macOS GUI (v3.5)

This is a native SwiftUI source package for macOS 13 or newer. Open the
`MacApp` folder in Xcode on a Mac, choose the `SafeScanMacApp` scheme, and run
it. The app lets a user choose a folder and calculates SHA-256 hashes locally;
it does not upload file contents or claim to replace a complete security suite.

The repository is developed on Windows, so this project has not been compiled
or signed here. macOS testing and an eventual notarized `.app`/DMG must be
performed on macOS with Xcode.
